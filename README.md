# Опубликованные исследования AbnormalTrading

Эта директория — самостоятельная статическая витрина для GitHub Pages.
В отдельный GitHub-репозиторий загружается **только её содержимое** с отдельной
историей Git. Главный репозиторий AbnormalTrading и его история не публикуются.

- `index.html` — оглавление исследований.
- `minute-replay/index.html` — полный последовательный проход по всем минутам
  657 инструментов, все попытки и повторные выбросы, включая затухание.
- `awakening-aria-evaa/dormant.html` — первые выбросы после затишья.
- `awakening-aria-evaa/index.html` — атлас ARIA/EVAA и реальных баллов модели.
- `research-publication.json` — список публикуемых файлов и SHA-256.
- `.nojekyll` — отдача готовых HTML/JS без преобразования Jekyll.

На сайте доступны интерактивные графики и экспорт разметки JSON. Разметка
сохраняется в localStorage каждого браузера, автоматически автору не передаётся.
При переходе с localhost прежнюю разметку нужно отдельно скачать: хранилища
разных адресов не объединяются.

## Обновление из основного проекта

```bash
python3 scripts/tools/research-pages.py build
python3 scripts/tools/research-pages.py validate
python3 scripts/tools/research-pages.py publish --repo OWNER/trading-research
```

При первой публикации добавить `--create`, чтобы создать отдельный публичный
репозиторий. Вход: `~/.local/bin/gh auth login --hostname github.com --git-protocol https --web`.
Команды выполняются из основного проекта; сам инструмент публикации остаётся
в `scripts/tools/research-pages.py` и не попадает на публичный сайт.

Сборка копирует только явный список HTML, JS, отчётов и компактных результатов.
Сырые parquet/NumPy, обученная модель, служебные логи и конфигурация приложения
не входят в этот список. При добавлении нового исследования расширяется
явный список сборки и оглавление.

Публикация использует временный отдельный checkout GitHub-репозитория. Она не
добавляет GitHub remote в основной проект и не отправляет его коммиты.
Существующий непустой репозиторий без маркера этой витрины не перезаписывается.
